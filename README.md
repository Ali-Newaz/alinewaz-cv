# Ali Newaz CV

A refined, responsive personal CV and portfolio landing page for MD. Ali Newaz.

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Deploy to Vercel

Import this repository into Vercel. It is a zero-build static site and will deploy without additional configuration.

Live target: `https://alinewaz-cv.vercel.app`
